## 📌 2. Operators Overview

### Arithmetic Operators

<img width="1125" height="698" alt="image" src="https://github.com/user-attachments/assets/9d438d0d-e065-4b61-8786-1a6349ec5558" />

| Operator | Name | Example | Result |
|---|---|---|---|
| `+` | Addition | `5 + 2` | `7` |
| `-` | Subtraction | `5 - 2` | `3` |
| `*` | Multiplication | `5 * 2` | `10` |
| `/` | Division | `7 / 2` | `3.5` |
| `%` | Modulus (Remainder) | `7 % 2` | `1` |
| `//` | Floor Division | `7 // 2` | `3` |
| `**` | Exponentiation | `2 ** 3` | `8` |
